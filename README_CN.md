# 商品因子驱动股票分析平台

基于商品期货价格因子，对相关 A 股进行量化分析、策略回测与监控的 Streamlit 应用。

---

## 快速启动

```bash
pip install -r requirements.txt
streamlit run app.py
```

---

## 项目结构

```
app.py                  # 主入口，UI 与页面路由
config.py               # 商品/股票静态配置、策略默认参数
data/
  fetcher.py            # 数据获取层（akshare → BaoStock → 本地缓存 → 模拟数据）
  cache.py              # SQLite 本地价格缓存
analysis/
  factors.py            # 因子计算（相关性、价差、Z-Score、领先滞后、回归）
backtest/
  engine.py             # Z-Score 均值回归回测引擎
monitor/
  watchlist.py          # 监控列表持久化（JSON）
  notifier.py           # 邮件信号推送（SMTP SSL）
```

## 功能模块

### 首页
- 根据所选商品自动匹配相关股票
- 计算全期相关性、年化波动率、当前 Z-Score
- 综合评分排名（相关性 60 分 + 波动率 20 分 + Z-Score 偏离 20 分）
- 显示当前买入/卖出信号

### 因子分析
- **价格对比**：两者归一化至 100，比较相对涨跌幅
- **滚动相关性**：滚动窗口内的 Pearson 相关系数曲线
- **价差 Z-Score**：当前价差偏离历史均值的标准差倍数
- **领先滞后分析**：交叉相关，判断谁先谁后
- **回归分析**：OLS 拟合 Y = aX + b，输出五项统计指标

### 策略回测
- Z-Score 均值回归策略，纯做多
- 支持自定义买入/卖出阈值、止损比例、初始资金
- 输出资金曲线、最大回撤、夏普比率、胜率等

### 监控
- 持久化 watchlist，刷新后展示最新信号
- 支持 QQ/163 等邮箱 SMTP 发送信号邮件

## 数据来源

数据获取采用四层降级策略：

```
akshare（实时）→ BaoStock（备用）→ 本地 SQLite 缓存 → 模拟数据（兜底）
```

| 层级 | 说明 |
|------|------|
| akshare | 商品：新浪期货主力连续合约；股票：东方财富日线前复权 |
| BaoStock | 免费 A 股历史数据，无需 token，网络兼容性更好 |
| 本地缓存 | SQLite 存储历史成功数据，断网后仍可使用 |
| 模拟数据 | GBM 几何布朗运动合成，仅用于所有源失败时保证 UI 可运行，**不具备研究价值** |

UI 上每个数据源均有明确标注：🟢 实时 / 🔵 缓存 / 🟡 模拟。

## 因子计算说明

### 归一化价格

$$P^*_t = \frac{P_t}{P_0} \times 100$$

将商品与股票统一归一化到同一起点（= 100），消除量纲差异后比较相对涨跌幅。

### 滚动相关性

$$\rho_t = \text{Pearson}(r^C_{t-N+1:t},\ r^S_{t-N+1:t})$$

在每个交易日，取过去 N 天的日对数收益率，计算 Pearson 相关系数。N 默认 60 天（约 3 个月）。

**滚动窗口选择建议：**

| 窗口 | 特点 | 适用 |
|------|------|------|
| 20～40 天 | 灵敏，噪音多 | 短线 |
| 60 天（默认） | 平衡 | 中线 |
| 90～120 天 | 平滑，信号滞后 | 中长线 |

### 价差 Z-Score

$$\text{Spread}_t = P^{C*}_t - P^{S*}_t$$

$$Z_t = \frac{\text{Spread}_t - \mu_t}{\sigma_t}$$

衡量当前价差偏离历史均值的程度（单位：标准差）。

| Z-Score | 含义 | 信号 |
|---------|------|------|
| < −2 | 股票相对低估 | 🟢 买入 |
| > +2 | 股票相对高估 | 🔴 卖出 |
| −2 ～ +2 | 正常范围 | 观望 |

### 领先滞后分析

$$\rho(k) = \text{Corr}(r^C_{t-k},\ r^S_t), \quad k \in [-10, +10]$$

| k | 含义 |
|---|------|
| k > 0 | 商品领先股票 k 天 |
| k < 0 | 股票领先商品 \|k\| 天 |
| k = 0 | 同步变动 |

### 回归分析（OLS）

$$Y = aX + b$$

$$a = \frac{\text{Cov}(X, Y)}{\text{Var}(X)}, \quad b = \bar{Y} - a\bar{X}$$

- X：商品日对数收益率
- Y：股票日对数收益率

| 输出参数 | 含义 |
|---------|------|
| Coefficient (a) | 斜率，商品涨 1% 时股票平均涨幅 |
| Constant (b) | 截距，与商品无关的基础日收益率 |
| Std Error | a 的标准误，越小越稳定 |
| P-value | < 0.05 说明关系统计显著 |
| R-squared | X 能解释 Y 波动的比例 |

## 回测策略说明

**策略类型**：Z-Score 均值回归，纯做多（Long-only）

**交易逻辑：**

```
每个交易日：
  持仓中：
    Z-Score > 卖出阈值  → 正常卖出（优先）
    浮亏 < 止损比例     → 止损卖出
  空仓且 Z-Score < 买入阈值 且 今天无其他操作 → 买入
```

**参数说明：**

| 参数 | 默认值 | 含义 |
|------|--------|------|
| 买入 Z-Score 阈值 | −2.0 | Z-Score 低于此值时买入 |
| 卖出 Z-Score 阈值 | +2.0 | Z-Score 高于此值时卖出 |
| Z-Score 窗口 | 60 天 | 计算价差均值/标准差的回看天数 |
| 止损比例 | −5% | 浮亏超过此比例时强制平仓 |
| 初始资金 | 10 万元 | 回测起始本金 |

**回测指标：**

| 指标 | 公式 | 含义 |
|------|------|------|
| 总收益率 | $(V_{末} - V_0) / V_0$ | 累计收益 |
| 年化收益率 | $(1+R)^{1/T}-1$ | 折算为每年等效收益率 |
| 夏普比率 | $\bar{r}_d / \sigma_d \times \sqrt{252}$ | 单位风险收益，> 1 为良好 |
| 最大回撤 | 从历史最高点到最低点的最大跌幅 | 衡量最坏情况 |
| 胜率 | 盈利笔数 / 总交易笔数 | 每笔交易平均获利概率 |

## 邮件通知

在监控 Tab 配置 SMTP 信息后，可将交易信号推送到邮箱。

以 QQ 邮箱为例：
1. 登录 QQ 邮箱网页版 → 设置 → 账户 → 开启 SMTP 服务
2. 生成授权码（16 位字母，非登录密码）
3. 填入监控页：服务器 `smtp.qq.com`，端口 `465`，授权码填入密码栏

无需付费，使用自有邮箱账号发送，发件人即为填写的 QQ 邮箱地址。
